# 블루래더 이미지 및 도표 제작 가이드

## 섹션별 이미지 기본 규칙

- 완성 글의 `##` 소제목 **하나당 고유 이미지 한 장을 반드시 만든다.** 대표 이미지는 별도이며, `###` 소제목은 기본적으로 이미지 수에 넣지 않는다.
- 이미지 제작 전 모든 소제목을 뽑아 섹션별 주제·이미지 형식·필요 데이터·삽입 위치를 계획한다. 정보가 다른 섹션에서는 같은 구성의 인포그래픽을 복제하지 않는다.
- **결과물은 섹션 본문 사이에 삽입**한다. 제목 또는 첫 설명 단락 직후에 배치하며 대표/보조 이미지를 글 아래에 모으지 않는다.
- 본문 이미지 기본 화면비는 **16:9**, 대표 이미지 기본 화면비는 **1:1**이다. 실제 수치 차트는 검증된 출처와 기준일, 단위를 표기한다.
- 모든 이미지의 생성 실패·품질 문제를 별도로 처리하고, 이미지 숫자를 채우려고 가짜 데이터로 제작하지 않는다.
- HTML·ZIP 납품은 `SKILL.md`의 `HTML·이미지 ZIP 납품` 규칙을 따른다. HTML 옆 `images/`에 파일을 두고 상대경로로 연결하며, base64로 삽입하거나 분리 과정에서 본문 이미지 태그를 없애지 않는다. 가독성을 유지하면서 최적화하고 최종 ZIP 실제 크기를 10,000,000바이트 이하로 검증한다.

## 시각 디자인

- 기본 대표 이미지: **1:1 정사각형**(권장 1024×1024px). 가로 이미지를 자르기보다 처음부터 정사각형 구도로 생성한다. 제목·얼굴·핵심 오브젝트는 잘림 방지를 위해 여백을 남긴다. 사용자가 별도 비율을 지정한 경우에만 예외로 한다. 낚시성 표정을 과장하지 않는다.
- 보조 그래프/설명 이미지: 별도 지정이 없다면 **16:9 가로형**으로 제작한다. 2:1 등 다른 비율은 사용자가 요청한 경우에만 적용한다.
- 기본 톤: 정제된 뉴스·재테크 매거진 무드, 넓은 여백, 한국어 모바일 가독성. 필요시 블루 계열의 포인트 컬러와 진회색 바탕. 엔비디아처럼 고유 브랜드 색이 중요한 주제라면 해당 색을 선택적으로 사용한다.
- 이미지 하나는 메시지 하나에 집중한다. 제목은 12~24자 안팎, 도표의 세부 내용은 3~5개 이하. 너무 많은 요소를 한 화면에 압축하지 않는다.
- 추세 그래프에는 x축 기간, y축 단위, 출처, 집계 기준을 반드시 표기한다. % 상승과 %p 변화는 다르게 표기한다.
- 숫자형 도표는 **정확성 우선**. 영업이익과 순이익, GAAP과 비GAAP, 회계연도와 달력연도, 실적과 가이던스를 섞지 않는다.
- 사용자 사진 업스케일에서 배율은 `최종 가로 픽셀 = 원본 가로 × 배율` 및 세로도 동일. 사용자가 `2배`를 가로세로 각각으로 요청하면 면적은 4배가 된다.

## 신뢰성과 인물 이미지

- 기존 인물 사진은 가급적 공식 회사 페이지, 언론의 사용 조건이 허용되는 원본, 사용자가 제공한 사진을 쓰고 출처를 밝힌다. 웹에서 찾았다는 이유만으로 재배포 권한이 생기는 것은 아니다.
- 사람이 관련된 루머에서 실존 인물이 함께 있는 합성 장면은 독자에게 사실처럼 오해를 줄 수 있다. 이런 주제는 실제 검증된 자료 또는 인물과 무관한 상징적인 삽화를 사용한다.
- AI로 만든 실제 기업의 발표 자료/주가 차트가 공식 자료처럼 보이지 않게 `제작 이미지` 및 기초 데이터 출처를 분명히 한다.
- 제품·회계 수치, 배경 인물 설명, 그래프의 막대 길이는 그림에 넣기 전에 원자료와 대조한다.

## 출판 전 체크리스트

1. 본문과 그래프의 기준일, 단위, 수치를 비교한다.
2. 대표 이미지의 가로·세로가 동일한지(1:1), 보조 그래프가 기본 16:9인지 확인한다. 사용자 지정 비율은 예외로 한다. 캔버스 사방에 잘린 글자/막대/로고가 없는지 확인한다.
3. 표지 글자가 모바일 너비에서도 읽히는지 확인한다.
4. 한글 맞춤법 및 영문 고유명사 표기를 확인한다.
5. 실사인지 AI 생성 이미지인지, 사진 출처를 독자가 오해하지 않게 표시한다.
6. 배경 용도의 이미지는 설명 문장에 없는 사건/행동을 사실처럼 묘사하지 않는다.
